Konveyor Denetim Sistemi - Gerekli Python Kutuphaneleri

Ana kurulum:

opencv-python-headless>=4.8.0
numpy>=1.24.0
PyYAML>=6.0
PyQt5>=5.15.0
pymodbus>=3.6.0

Raspberry Pi kamera:

picamera2

Notlar:

- picamera2 Raspberry Pi OS uzerinde genelde sistem paketi olarak gelir.
- Sanal ortam klasorunu USB'ye tasimak yerine hedef cihazda yeniden kurulum yapmak daha sagliklidir.

Kurulum komutu:

pip install -r requirements.txt

Raspberry Pi'de PyQt5 veya picamera2 pip ile kurulmazsa apt paketleri gerekebilir:

sudo apt install python3-pyqt5 python3-picamera2
